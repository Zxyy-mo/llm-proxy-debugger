# 用网关完成一次 Agent 排障

## 启动与接入

在仓库根目录执行（macOS、Linux、PowerShell 均可）：

```sh
npm --prefix web ci
npm --prefix web run build
go run ./cmd/proxy -listen 127.0.0.1:12337 -target http://127.0.0.1:28000/v1 -logdir log
```

把 `-target` 换成实际的上游 Base URL，打开 **http://127.0.0.1:12337/ui/**。客户端或 SDK 的 Base URL 改为 **http://127.0.0.1:12337/v1**，保留原有模型名和鉴权。上游已经包含 `/v1` 时不会再次拼接它。

需要多个上游时，在“管理 → Provider 与路由”填写地址、模型匹配和密钥环境变量名。密钥变量必须先存在于启动网关的进程环境中。网关只保存变量名；也可以继续透传客户端鉴权。

可以直接选择 CPA、New API、Sub2API 或 vLLM 接入预设。填写真实地址后保存，在“查询模型并配置路由”查询这个实例的模型列表，再新建或填入已有路由。临时查询密钥提交后清空；模型列表成功只说明本次列表接口可读。Chat、Responses、Messages 和模型列表各自的未知/支持/不支持声明，以及历史/WebSocket 开关，按实例实际能力设置。示例见 [兼容接入契约](contracts/compatible-providers.md)。

## 按一轮任务查看调用

调用方在同一轮请求中复用 `X-Run-ID`，下一轮换成新的标识；可同时提供 `X-Session-ID` 表示持续对话。JSON 中的 `metadata.run_id` 也可用，和头部同时提供时需要同值。

```sh
curl 'http://127.0.0.1:12337/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -H 'X-Session-ID: my-conversation' \
  -H 'X-Run-ID: task-001' \
  -d '{"model":"your-model","messages":[{"role":"user","content":"定位并修复这个问题"}]}'
```

会话中的“一轮任务”选择框按服务器确认的 Run 筛选请求，并显示请求、尝试和进行中的请求数量。并发和分支可以归于同一轮，画布仍展示会话全貌。没有有效标识的请求留在“未关联任务”；网关不根据时间、工具 ID 或相同会话猜测任务边界。

在“路由与上游尝试”查看每次发送的目的地、状态、头部耗时和结束耗时，点击“查看此次出站”或下载完整正文。发生切换时，每次快照独立保留；旧“原始 / 出站”入口的出站仍指最后一次尝试。中转站内部的供应商切换不在此列表中。详情见 [四层调用契约](contracts/call-layers.md)。

## 找到问题调用

选择会话，在“查找请求”中输入模型、摘要、路径、Trace 或错误关键词。“请求状态”可筛选失败、等待、进行中、完成或取消；“请求排序”可优先显示耗时最长的调用。

点击请求行会聚焦到可读的图节点。筛选只影响列表，父调用和工具关系仍保留在画布中。“显示全图”恢复总览，手动缩放不会被指标更新打断。手机可在“筛选请求”中设置条件，再用“当前请求”选择目标。

## 检查上下文并修改

在调用详情点击“上下文变化”，查看实际父调用与当前请求的消息、系统指令和工具定义差异。没有已捕获的父调用时可手动选择比较对象；网关不会把时间相近当成因果关系。

点击“编辑并重放”，选择“实际出站请求”或“客户端原始请求”。出站请求保留当时的目的地和修改，不重复应用规则；原始请求会重新经过当前规则。修改正文或允许的请求头，查看“变更对比”，然后填写本次鉴权并校验。

在上下文、画布、详情和同一工作台之间切换，草稿会保留。查看重放结果后可用“返回重放工作台”回到来源；明确换到另一来源时，凭证输入会清空。凭证和未确认提交只保存在当前页面内存，不写入浏览器存储。

## 执行与比较

点击“发送修改后的请求”或“原样重放”。运行中的调用始终可取消；重置草稿不会清除已经开始的执行。刷新页面不会重新发送，进行中的记录可以从原来源的重放历史找回。

每次明确重放都会生成独立 Run 和请求，保留来源关系；复用同一个幂等键仍对应原执行。原始报文中的旧任务字段不会导致这次重放混入来源任务。

“对比来源响应”把来源和结果的状态、错误、模型、输出和指标放在一起。Token 区分 Provider usage、字符估算与未知；只有可比的已知值才显示差值。输出摘录有长度上限，完整 JSON/SSE 原文可分别翻页、直达末段或下载。

若出现“发送结果尚未确认”，先点击“恢复本次重放”查询已有记录。仍未找到时，“使用原次提交重试”保留原请求和同一个幂等键。不要把结果不明理解为没有执行；界面会阻止隐式创建另一笔重放。

## 回查与保留

“管理 → 历史记录”支持查询和分页，打开调用后用“返回历史查询”回到原条件和页码。清理跳过活动请求，并保留存活记录仍需使用的还原映射。

新采集的脱敏占位符按会话和上游鉴权身份隔离；晚到关联不会改写历史占位符。旧版本记录沿用原有还原范围。SQLite 与正文文件需要一起备份；普通元数据仍采用合并保存，新重放登记则在出站前同步保存。

完整边界见 [接口契约](README.md)，最新可复现检查见 [四层调用验收](../output/playwright/call-layers/verification.md) 和 [兼容接入验收](../output/playwright/compatible-provider-setup/verification.md)。
